# FORECAST TACTICS

敵が次にすることが全部見えている盤で、1手ずつ動いて、当たらずにゴールへ着く（または敵を全滅させる）詰め戦術パズル。ブラウザで動く。TypeScript + Vite + Canvas。
[web-game-template](https://github.com/pupe-xxx/web-game-template) から作った。STRATA の「予約移動」を、敵の予告として使ったもの。運の要素は無い。

## 遊び方

1ターンの流れ：自分が1手打つ → 弓兵が予告どおりに撃つ → 追手が予告どおりに動く → 次の予告が出る。

- **自分**（水色の丸）: 隣のマスをタップすると動く。隣に敵がいれば、そのマスをタップして倒す（自分は動かない）。「その場で待つ」か、自分のマスをタップすると、動かずにターンを進める
- **追手**（赤い三角）: 自分に一番近づく隣のマスへ入る。入るマスが赤く出る。そのマスに居ると当たる。穴も避けないので、誘い込めば落ちる。入る先にほかの敵がいれば動かない
- **弓兵**（紫の四角）: 動かない。まっすぐ先（5マスまで）に自分が見えると、次のターンにその向きへ撃つ。撃つ線が赤く出る。矢は最初に当たった駒に刺さるので、線から出て敵に当てさせることもできる
- **壁**（灰色）: 通れない。矢も止める
- **穴**（黒）: 自分は入れない。追手は落ちる
- 金色の輪があるステージは、そこに着くとクリア。無いステージは、敵を全滅させるとクリア
- ターン数が最少なら ★3、2ターン多くまでは ★2、6ターン多くまでは ★1。それでもクリアできないか、当たると失敗

ステージは24個。最初の3つは遊び方を覚えるためのもの。クリアした一番先のステージの、2つ先まで遊べる。

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす |
| `npm test` | ルールの自動テスト。全ステージが解けることと、★3 のターン数が最少であることも確かめる |
| `npm run check` | 全ステージを解いて、最少のターン数と手順を出す |
| `npm run gen` | ステージを作り直す（`src/game/levels.gen.ts` を書き出す） |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す |
| `npm run typecheck` | 型の検査（ルール側が画面に触れていないかも見る） |
| `npm run build` | 検査してから `dist/` に公開用のファイルを作る |

## フォルダ

```
src/
  main.ts    入口
  kit/       どのゲームでも使う共通部分（型のまま）
  game/      ルール。画面の処理に触れない
    hex.ts         六角形の盤の座標
    rules.ts       自分の手・敵の予告と動き・クリアと失敗の判定・星の数
    solve.ts       総当たりで最少のターン数を求める
    levels.ts      ステージの一覧（最初の3つは手作り）
    levels.gen.ts  scripts/gen.ts が書き出したステージ
  ui/        描画と操作
    shell.ts       ステージ選択・結果・星の保存（ステージ制のパズルに共通の外枠）
    game.ts        このゲームの盤と予告の描画、タップの処理
    hexview.ts     六角形の盤を描くための座標の計算
    i18n.ts        日本語と英語の切り替え（ブラウザの言語で決まる）
scripts/
  gen.ts     ステージを作る
  check.ts   全ステージを解いて確かめる
  record.ts  動作記録を取り直す
tests/
```

`src/ui/shell.ts`・`hexview.ts`・`i18n.ts`・`style.css` と `src/game/hex.ts` は、ROLLER BREAK と同じもの。

## ステージの作り方

`scripts/gen.ts` が、乱数で盤を作り、総当たりで解いて、次の条件を満たすものだけ残す。乱数の種は固定なので、何度実行しても同じステージができる。

- 解ける。最少のターン数が、その段階の範囲に入っている
- 始まった時に、隣に敵がいない
- ゴールのあるステージは、まっすぐ歩くより2ターン以上かかる
- 全滅させるステージは、待っているだけでは全滅しない
- 最少の手順のうち、待つ手が半分以下

段階は `scripts/gen.ts` の `TIERS` にある。変えたら `npm run gen` → `npm run record`。

## 守ること

型の README と同じ。特に次の2つ。

- **`src/game` は画面に触れない。** `Math.random` も時計も使わない
- **ルールやステージを意図して変えたら、動作記録を取り直す（`npm run record`）。**

## 公開

`main` に push すると、テスト → ビルド → GitHub Pages への公開まで自動で進む。
ゲームサイト（Poki・CrazyGames など）の広告 SDK は入っていない。差し込み口は `src/kit/platform/`。やり直しと次のステージの前に、区切りの広告を呼ぶ作りになっている。
